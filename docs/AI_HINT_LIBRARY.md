# Библиотека точечных подсказок для DeepSeek Harness

> Практическое приложение к [AI_STUDIO_PLAYBOOK.md](AI_STUDIO_PLAYBOOK.md). **Шаблоны решений, не подтверждение наличия установленного инструментария.** Использовать только подсказки, которые относятся к текущей задаче. Дата: 2026-10-24.

## Алгоритм извлечения подсказок

1. Прочитать карточку задачи и указанные в ней канонические документы.
2. Назвать проблему одной фразой («нет исходного PNG», «нет сцены», «атака нечитаема», «контрольная проверка не прошла»).
3. Взять одну ближайшую подсказку ниже; записать гипотезу и проверяемый ожидаемый результат.
4. Выполнить одно небольшое изменение/эксперимент, проверить его.
5. Если новая информация не появилась после двух существенно разных диагностических попыток — оформить `BLOCKER`, запросить решение по существу, а не бесконечно перегенерировать код.

## H-01 — Документы расходятся

**Симптом:** один документ говорит «2D Pixel Art», другой — «стилизованное 3D/2.5D».

**Подсказка:** искать более позднее явно утверждённое решение. У этой игры **утверждённый формат — стилизованное 3D/2.5D**. Помечать древние инструкции как legacy; менять устаревший документ отдельным малым коммитом, не переписывая механику.

## H-02 — Референс указан, но изображения нет в репозитории

**Симптом:** запись каталога существует, `assets/references/...png` отсутствует.

**Подсказка:** проверить конкретный файл через Git/GitHub и дерево. Не создавать заглушку под названием оригинального референса. Поставить задачу «импорт PNG», указать из какого чата/архива взять оригинал, и оставить игровой ассет помеченным как временный.

## H-03 — Генерация модели/спрайта не соответствует канону

**Симптом:** вместо русского средневекового врага получается европейский рыцарь, оружие эпохи огнестрела или фантастический скафандр.

**Подсказка:** проверять сначала силуэт, одежду и вооружение по `BESTIARY.md`, затем узнаваемость на игровом расстоянии. Отрицательные ограничения: никаких футуристических деталей, пистолетов или неверной боевой роли. Один концепт ≠ готовая модель.

## H-04 — На игровом масштабе всё сливается

**Симптом:** сложные поверхности и эффекты делают бой нечитаемым.

**Подсказка:** проверить сцену в целевом ракурсе и масштабе, временно выключить сложный свет/постобработку, усилить контраст врага к полу, добавить телеграф и отдельно проверить попадание, блок и уворот. Приоритет — читаемость, а не количество мелких деталей на концепт-арте.

## H-05 — Поведение врага не соответствует группе

**Симптом:** звонарь кастует заклинания или обычный ратник слишком похож на босса.

**Подсказка:** смотреть роль семейства из `BESTIARY.md`: ратник = базовая пехота; звонарь = тяжеловес ближнего боя; волхв = некромант; стрелок = дистанция. Изменение роли — вопрос владельцу, а не повод самостоятельно перепроектировать противника.

## H-06 — Реализация AI/навигации застряла

**Симптом:** враг не видит игрока, не находит путь, атакует через стены, коллизии сломаны.

**Подсказка:** изолировать минимальную сцену с одним врагом, проверить состояния `idle → notice → approach → windup → strike → recovery`, коллизии и расстояния численно; только после этого добавлять анимации, группы, сложные реакции. Метод/названия API зависят от реально выбранного движка.

## H-07 — Нет конкретных характеристик и фаз

**Симптом:** у босса есть картинка, но отсутствуют утверждённые урон, HP, атаки и фазность.

**Подсказка:** не выдумывать канонические числа. Разрешены ясно помеченные **временные тестовые значения** в прототипе, отделённые от окончательного GDD. Подготовить небольшой список решений для владельца.

## H-08 — Система ломается после изменения

**Симптом:** отдельно компонент проходит тест, в общей сцене возникают ошибки.

**Подсказка:** воспроизвести тот же сценарий в полной интеграции, проверить контракты события, жизненный цикл объектов, путь ресурсов, версию движка. Минимальная правка → локальный тест → полный запуск тестовой сцены. Не объявлять исправление успешным без интеграционного подтверждения.

## H-09 — Зависимости, запуск и плагины

**Симптом:** команда запуска или модуль не найден.

**Подсказка:** прежде чем устанавливать что-либо, проверить реальную ОС, версию движка, конфигурацию проекта, разрешённые директории и доступные команды. Не подменять проверку придуманными путями. Новые платные сервисы и опасные команды требуют согласования.

## H-10 — Сессия/контекст заканчивается

**Симптом:** агент близок к лимиту контекста либо потерял прошлую задачу.

**Подсказка:** оставить краткую записку передачи: последняя задача, цель, рабочая ветка, изменённые файлы, воспроизводимая команда, статус проверок, незавершённое, следующий единственный шаг. Новый сеанс читает записку + канон, а не весь чат. Не переписывать задачи с нуля.

## H-11 — Повторная ошибка без прогресса

**Симптом:** два цикла дали ту же ошибку.

**Подсказка:** прекратить попытки. Сформировать `BLOCKER` и отправить на анализ с точным сообщением, логом, версиями и двумя уже проверенными гипотезами. После получения новой подсказки действовать по одному эксперименту.

## H-12 — Измерение стоимости/качества

**Симптом:** много токенов уходит без готовых результатов.

**Подсказка:** фиксировать для каждой карточки завершённые артефакты, число итераций и расход/время, если такие метрики реально доступны. Не выдумывать счётчики. Оптимизировать контекст (файлы по требованию, короткие логи, маленькие задачи) раньше, чем снижать качество проверки.

## Обучение на ошибках

После действительно нового проверенного решения добавить в этот файл одну короткую карточку с условиями, проверкой и подтверждённым результатом. **Не** сохранять ненадёжные догадки как установленный факт. Если подсказка затрагивает геймдизайн/визуальный канон — сначала получить утверждение владельца.

## Пример просьбы о помощи вместо «я застрял»

```text
BLOCKER: ENEMY-E01-01
Среда: <реальная ОС, движок, версия>
Ветка/коммит: <реальные значения>
Ожидалось: после обнаружения игрока враг начинает сближение.
Получилось: враг стоит на месте; в логе: <дословный фрагмент>.
Проверено: 1) ...; 2) ...
Нужна подсказка: какую одну проверку сделать следующей и почему?
```

## H-13 — DeepSeek начал полировать модель слишком рано

**Симптом:** хочет делать финальную кольчугу/ткани/лицо, пока движение и атаки не проверены.

**Подсказка:** открыть [CHARACTER_PRODUCTION_PIPELINE.md](CHARACTER_PRODUCTION_PIPELINE.md), определить последнюю пройденную стадию. Если P1–P4 не закрыты, вернуться к простой PROXY-модели. Запуск и читаемость первичны; детализация — P6 после рабочего vertical slice. Предъявить кадр с игровой камеры.

## H-14 — Движения выглядят деревянно или неестественно

**Симптом:** ноги едут, удар без веса, постоянное дёргание на переходах или атака не совпадает с коллизией.

**Подсказка:** открыть stage P3/P7. Разделить проблему на **риг → исходный клип → retarget → blend → root motion/контроллер → события удара → IK**. Проверять по одному звену, с side-by-side видео до/после, не генерировать с нуля все кадры по догадке.

## H-15 — Сцена работает, но непонятно, «красиво» ли

**Симптом:** все автоматические тесты PASS, но нет записи с настоящей камеры и нет художественного сравнения.

**Подсказка:** `NOT_VERIFIED` по визуальному GATE, а не финальный PASS. Показать turntable, снимок на игровом масштабе и короткий клип атаки/ходьбы. При необходимости оставить `NEEDS_REVIEW` для решения владельца.

## H-16 — Полировка сломала рабочую механику

**Симптом:** после замены mesh/анимаций враг теряет оружие, попадает без замаха или проваливается в землю.

**Подсказка:** сохранить базовый PASS-коммит, проверить путь модели, риг/аватар, привязку оружия, события клипа и hit windows; вернуть/исправить только затронутый компонент, затем выполнить smoke test против игрока. Не переписывать все контроллеры ради косметической правки.

## H-17 — Критерии качества не определены

**Симптом:** агент сообщает «анимация готова», но это только наличие клипа.

**Подсказка:** заполнить матрицу P0–P8 из [конвейера](CHARACTER_PRODUCTION_PIPELINE.md): канон, геометрия, движение, читаемость, интеграция; указать `PASS/FAIL/NOT_VERIFIED` и приложить действительные артефакты. Не подменять художественное качество тестами компиляции.

## H-18 — Нет утверждённого референса

**Симптом:** хочется «примерно представить», как выглядит враг/босс/локация, у которых нет утверждённого изображения.

**Подсказка:** ничего не придумывать. Сверить [BESTIARY.md](BESTIARY.md) раздел 0 и [CONCEPT_ART_INDEX.md](CONCEPT_ART_INDEX.md); если статус не `VISUAL_APPROVED` — вернуть `BLOCKED_NEEDS_REFERENCE`, перечислить, что именно нужно от владельца (ракурсы, разрешение, формат), и остановиться на этой единице. Продолжать только работу без выдумывания внешности (код, инструменты, серый бокс, документация). Кандидат — не разрешение на финальный арт.
