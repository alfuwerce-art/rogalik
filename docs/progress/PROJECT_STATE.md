## 4. Готовые игровые системы

- **Godot-проект запускается**: `game/prototype` (viewport 480×270, окно 960×540, `gl_compatibility`, nearest-фильтр). Главная сцена — `scenes/location.tscn`; техническая комната Этапа 1 сохранена как `scenes/main.tscn`.
- **Каркас локации (задача 2.1)**: слои земля → детали пола → коллизии → препятствия → перекрытия → персонажи → атмосфера; тайлсет собирается в рантайме с физическим слоем (стены и частокол непроходимы); техническая зона-«ворота» с коллизиями столбов и Area2D-зоной; прозрачность перекрытий (арка, крона) при герое под объектом; ночная тонировка `CanvasModulate` + два тёплых `PointLight2D`; HUD с константами и FPS.
- **Утверждённые константы (D16, профиль B)**: тайл 24 px, герой 48 px, zoom 1.0, 4 направления, 480×270, окно 960×540 (2×). Обычный запуск проекта использует их; профили A (16 px / zoom 2) и C (32 px / zoom 1) остаются диагностическими (`--profile=a|c`).
- **Проба боевого пространства (2.2)**: `--probe` ставит героя в ячейку (19, 9), рисует `PROXY_TECHNICAL`-маркеры предполагаемых боевых объектов (1.8 / 4.5 / 7 тайлов) в пиксельном стиле и печатает `PROBE_VISIBLE` (маркеры в кадре и выше HUD).
- **Запись клипа (2.4)**: `--demo` — маршрут из 6 отрезков (подход с юга → под аркой → столкновение со столбом → отход → движение по двору → возврат), запись встроенным Godot Movie Maker (`--write-movie`), упаковка компактной версии — `tools/stage2_location/make_clip_webp.py`.
- **Герой (задачи 3.1 → 3.1b)**: лист `art/sprites/hero_idle_48.png` — 256×48, 8 кадров 32×48 (4 направления × 2 кадра `idle`), экспорт Pixelorama CLI из `tools/stage3_hero/source/hero_idle_48.pxo`; текущая арт-версия — **3.1b** (светотень в 4 тона кожи, плечи 20 px, талия 8 px, повязка в 3 ряда с узлом и концами, обмотки темнее кожи, рваные штаны, босые стопы). Направление выбирается по доминирующей оси движения, `idle` — два кадра дыхания (1.4 кадра/с), спрайт привязан к целому пикселю, `--face=down|up|left|right` задаёт стартовое направление. Диагностические профили A и C по-прежнему используют односторонние прокси (`hero_directional=false`).
- **Калибровочный кадр (задача 3.1b)**: сцена `game/prototype/scenes/calibration.tscn` + `scripts/world/calibration.gd` — двор ночной древнерусской деревни на неизменных константах D16: сруб с тёплыми окнами, белокаменная часовня с порталом, врата с факелами, частокол, силуэт ночного леса, мёртвое дерево с красными лоскутами, вытоптанный тракт с лужами, настил, мелкие пропсы, 3 слоя тумана и виньетка. Свет **запечён** (аддитивные дизеренные пятна): динамический `PointLight2D` измеримо ломал пиксельную чистоту (5–6 блоков 2×2). Флаги: `--walk` (клип), `--face=`, `--lights`, `--no-lights / --no-baked / --no-fog / --no-vignette` (диагностика). Главная сцена и локация Этапа 2 не менялись.
- **Управление**: WASD/стрелки, кадровая анимация, авто-режим `--auto=dx,dy` для прогонов без клавиатуры.
- **Инструменты проверки**: автолоад скриншота `Capture` (`--shot`), MCP-мост `McpInteractionServer` (`127.0.0.1:9090`), `tools/stage2_location/` (генераторы, проверка пиксельной сетки и швов).

## 6. Реальные блокеры

Нет. Ограничения (не блокеры):

- Публикация: обычный push в рабочую ветку этапа выполняется автоматически после проверок (D14); прямой push в `main`, force push, переписывание истории и merge в `main` запрещены навсегда.
- **Push через инструмент требует разового расширения прав песочницы:** MSYS-shell (`sh.exe`), которым git запускает Git Credential Manager, внутри песочницы падает (`couldn't create signal pipe, Win32 error 5`). Обычные команды `git push` вне песочницы (в терминале владельца) работают штатно. Это ограничение среды, а не репозитория.
- `mcp__godot__*` доступны только в сессиях пресета `Rogalik Dev`.
- `mcp__godot__read_scene` принимает путь **без** `res://` (`scenes/main.tscn`).
- **Локальные игровые референсы:** наличие четырёх игр (Children of Morta, Hyper Light Drifter, Hades II, Path of Exile 2) **заявлено владельцем**, но агентом **не проверено** — `OWNER_REPORTED / NOT_VERIFIED_LOCALLY`. Регламент исследования — [GAME_REFERENCES.md](../GAME_REFERENCES.md) (**D18** — состав, **D19** — локальный доступ `LOCAL_GAME_REFERENCE / READ_ONLY`). Фактические пути к установкам ведутся локально и в публичный репозиторий не публикуются. Это ограничение, а не блокер: разработка задачи 3.2 от референсов не зависит.
- **Children of Morta не установлена (проверено 2026-10-26 в рамках D19):** в доступной библиотеке Steam присутствуют Hades II и Path of Exile 2; Children of Morta отсутствует, Hyper Light Drifter не установлен (нулевой размер). Поэтому сравнение с CoM по `REFERENCE_FIDELITY_GATE` — **`NOT_VERIFIED`**; в сравнительном листе 3.1c её нет. Если владелец хочет этот ориентир в листе — игру нужно установить локально.
- Для E01–E03, B01–B05 референсы есть; E05–E10 и B06–B09 — `NO_REFERENCE` → `BLOCKED_NEEDS_REFERENCE`.
