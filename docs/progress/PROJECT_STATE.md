## 4. Готовые игровые системы

- **Godot-проект запускается**: `game/prototype` (viewport 480×270, окно 960×540, `gl_compatibility`, nearest-фильтр).
- **Сцена `main.tscn`**: пол, стены (4 коллизии), препятствие, `Player` (`CharacterBody2D` + `Sprite2D` 4 кадра + коллизия), `Camera2D`, HUD-подсказка.
- **Управление**: WASD/стрелки, кадровая анимация, авто-режим `--auto=<dir>` для прогонов.
- **Инструменты проверки**: автолоад скриншота `Capture`, MCP-мост `McpInteractionServer` (`127.0.0.1:9090`).
- **Пайплайн пиксель-арта**: `.pxo` → Pixelorama CLI → PNG/листы → атлас + JSON (`tools/pixel_pipeline`), валидатор `PASS/FAIL`.
- **Боевых систем, врагов, локации, UI — нет.**
