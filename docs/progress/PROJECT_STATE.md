## 4. Готовые игровые системы

- **Godot-проект запускается**: `game/prototype` (viewport 480×270, окно 960×540, `gl_compatibility`, nearest-фильтр). Главная сцена — `scenes/location.tscn`; техническая комната Этапа 1 сохранена как `scenes/main.tscn`.
- **Каркас локации (задача 2.1)**: слои земля → детали пола → коллизии → препятствия → перекрытия → персонажи → атмосфера; тайлсет собирается в рантайме с физическим слоем (стены и частокол непроходимы); техническая зона-«ворота» с коллизиями столбов и Area2D-зоной; прозрачность перекрытий (арка, крона) при герое под объектом; ночная тонировка `CanvasModulate` + два тёплых `PointLight2D`; HUD с константами и FPS.
- **Утверждённые константы (D16, профиль B)**: тайл 24 px, герой 48 px, zoom 1.0, 4 направления, 480×270, окно 960×540 (2×). Обычный запуск проекта использует их; профили A (16 px / zoom 2) и C (32 px / zoom 1) остаются диагностическими (`--profile=a|c`).
- **Проба боевого пространства (2.2)**: `--probe` ставит героя в ячейку (19, 9), рисует `PROXY_TECHNICAL`-маркеры предполагаемых боевых объектов (1.8 / 4.5 / 7 тайлов) в пиксельном стиле и печатает `PROBE_VISIBLE` (маркеры в кадре и выше HUD).
- **Управление**: WASD/стрелки, кадровая анимация, авто-режим `--auto=dx,dy` для прогонов без клавиатуры.
- **Инструменты проверки**: автолоад скриншота `Capture` (`--shot`), MCP-мост `McpInteractionServer` (`127.0.0.1:9090`), `tools/stage2_location/` (генераторы, проверка пиксельной сетки и швов).
- **Пайплайн пиксель-арта**: `.pxo` → Pixelorama CLI → PNG/листы → атлас + JSON (`tools/pixel_pipeline`), валидатор `PASS/FAIL`.
- **Боевых систем, врагов, UI-экранов — нет.**

## 6. Реальные блокеры

Нет. Ограничения (не блокеры):

- Публикация: обычный push в рабочую ветку этапа выполняется автоматически после проверок (D14); прямой push в `main`, force push, переписывание истории и merge в `main` запрещены навсегда.
- **Push через инструмент требует разового расширения прав песочницы:** MSYS-shell (`sh.exe`), которым git запускает Git Credential Manager, внутри песочницы падает (`couldn't create signal pipe, Win32 error 5`). Обычные команды `git push` вне песочницы (в терминале владельца) работают штатно. Это ограничение среды, а не репозитория.
- `mcp__godot__*` доступны только в сессиях пресета `Rogalik Dev`.
- `mcp__godot__read_scene` принимает путь **без** `res://` (`scenes/main.tscn`).
- Для E01–E03, B01–B05 референсы есть; E05–E10 и B06–B09 — `NO_REFERENCE` → `BLOCKED_NEEDS_REFERENCE`.
